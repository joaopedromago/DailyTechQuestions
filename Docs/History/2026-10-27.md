# UI foundation and home shell

Added the gluestack and NativeWind UI foundation, replaced the starter tabs with the study menu,
and added temporary question and quiz setup routes. Continue remains disabled until quiz-session
support is implemented.

Verified Android, iOS, and web JavaScript exports, the web shell, and the iOS development build and
routes in light and dark appearance. The Android native debug build compiles; an Android device UI
check remains pending because no Android emulator or device is configured.

## Appearance toggle and shared control conventions

Added a menu toggle between light and dark appearance, with Material Icons from React Native Vector
Icons. Web stores the selection on the document root; native platforms use React Native appearance.
Documented the component-plus-`className` convention and reserved shared button, input, and checkbox
folders for future reusable variants; no shared controls were created.

## Question browsing, quizzes, and resumable sessions

Implemented catalog browsing with category and normalized text filters, shared progressive answer
details, random quiz navigation, and local quiz-session persistence. Continue restores the exact
ordered snapshot and position; completion clears it. Updated the study contracts and removed the
shipped items from the TODO list.

## iOS theme and route rendering fixes

Applied the semantic light and dark palette at the native app root, standardized search placeholder
contrast, and gave pushed study routes explicit native flex sizing so browse and quiz screens render
their content on iOS. Verified the menu, quiz setup, active quiz, and question list in both themes on
an iOS simulator.

## Collapsible answer disclosure

Made the answer control toggle the quick and full answer panel with an expanded-state accessibility
value and matching expand/collapse icons. The open panel shows the question category.
