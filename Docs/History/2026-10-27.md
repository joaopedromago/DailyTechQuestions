# UI foundation and home shell

Added the gluestack and NativeWind UI foundation, replaced the starter tabs with the study menu,
and added temporary question and quiz setup routes. Continue remains disabled until quiz-session
support is implemented.

Verified Android, iOS, and web JavaScript exports, the web shell, and the iOS development build and
routes in light and dark appearance. The Android native debug build compiles; an Android device UI
check remains pending because no Android emulator or device is configured.

## Appearance toggle and shared control conventions

Added a menu toggle between light and dark appearance, with Material Icons from React Native Vector
Icons. Web stores the selection on the document root; native platforms use React Native appearance.
Documented the component-plus-`className` convention and reserved shared button, input, and checkbox
folders for future reusable variants; no shared controls were created.
