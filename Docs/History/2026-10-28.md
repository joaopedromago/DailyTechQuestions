# Backend, system design, and JavaScript code questions

Added System Design and Backend categories, moved existing general backend questions out of Node,
and added JavaScript output-prediction questions. JavaScript code questions display a fixed prompt
with the stored source snippet in a monospace block.

# Copy question prompt or code

Added a copy icon beside the question prompt in browse and quiz detail views. It copies the stored
question text, including raw JavaScript code snippets, and reports clipboard write failures.

# Fix web code preview line truncation

Handled `numberOfLines` in the web Text component with CSS line clamping, preventing the prop from
reaching a DOM element while preserving one-line JavaScript code previews.
